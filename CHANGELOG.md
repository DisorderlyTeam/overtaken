# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

This project uses a versioning scheme inspired by Semantic Versioning:

- major versions indicate significant overhauls or breaking changes,
- minor versions add new features or content,
- patch versions contain bug fixes and other small improvements.

## [0.1.2] - 2026-11-16

### Added

- Game logo
- Release build binary size optimizations
- Gamepad button prompt icons
- Speedrun timer for each level
- Level completion screens
- Ukrainian localization by Kосмічний Kіт
- Kashubian localization by Akino
- Translation attributions now visible in option screen
- Level selection and unlocking

### Changed

- Changed heading font from Jersey10 to Tiny5 Duo

### Fixed

- Fixed text rendering behavior
- Improved localization handling, including falling back to English
- Fixed game opening wrong level after going back to title screen

## 0.1.1 - 2026-07-06

First public release available on itch.io and GameJolt.

### Changed

- Reduce the difficulty of the chase section in level 1.

## 0.1.0

Initial internal release presented on the ZTGK contest.

### Added

- Two playable levels.
